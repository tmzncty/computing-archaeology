# Manufacturing Track Acknowledgements — Field Set 5: Facilities and Purity

This field set is about infrastructure whose success is usually recorded as an absence:

- no particle landed on the critical surface;
- no ion contaminated the rinse;
- no gas leaked;
- no pump backstreamed enough to matter;
- no floor motion broke the alignment budget;
- no static event damaged the product;
- no scrubber or exhaust failure exposed the fab;
- no chiller excursion stopped the tool.

That makes facilities work especially easy to erase from computer history.

## Preservation targets

Facilities evidence disappears quickly because retired infrastructure is bulky, dirty, hazardous, proprietary, and rarely collectible.

Future preservation should save where possible:

- UPW process diagrams;
- cleanroom airflow drawings;
- filter specifications;
- gas-panel and gas-cabinet manuals;
- high-purity piping standards;
- vacuum-pump manuals and service records;
- chiller/PCW schematics;
- vibration surveys;
- ESD-control procedures;
- exhaust balance reports;
- scrubber manuals;
- alarm/interlock logic;
- BMS screenshots and trend data;
- maintenance procedures;
- training manuals;
- oral histories from facilities technicians.

These records show the difference between a process recipe that works once in a laboratory and a factory that can run it every day.
