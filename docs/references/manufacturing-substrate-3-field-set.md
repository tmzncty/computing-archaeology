# Manufacturing Substrate — Field Set 3 Source Map

This field set covers ion implantation, lithography capital equipment, automatic test, wire-bond reliability, flip-chip packaging, SMIF/minienvironments, and the design-rule/EDA/fab interface.

The purpose of this file is to preserve source type and caveat information, not merely URLs.

## Cross-cutting equipment-industry source

CHM's “Turnkey Equipment Suppliers Change Industry Dynamics” is useful across this field set because it explicitly documents the historical shift from semiconductor firms building most equipment themselves toward specialized front-end/back-end vendors.

- https://www.computerhistory.org/siliconengine/turnkey-equipment-suppliers-change-industry-dynamics/

This source should not be used as a substitute for vendor-specific manuals when exact machine capability matters.

## Source-handling cautions

1. Equipment-vendor chronology is not the same as process-invention chronology.
2. Trade press can document adoption while still repeating company claims.
3. NASA reliability literature often concerns high-reliability or hybrid environments and should not be generalized automatically to every commercial package.
4. Modern packaging terminology can clarify mechanisms but must not be projected backward as period language.
5. “First” claims for steppers, mask writers, flip-chip, and automated handling require explicit criteria.
6. Design-rule abstraction should not be written as though modern PDKs existed unchanged in the 1970s.

## Labor and preservation targets

Future work should recover, where sources permit:

- implanter operators and service engineers;
- mask-shop artists, camera operators, reticle writers, and inspectors;
- wafer-probe and ATE operators;
- test-program engineers;
- failure-analysis technicians;
- wire-bond and package-line operators;
- X-ray / acoustic inspection workers;
- cleanroom material handlers;
- robot/SMIF maintenance technicians;
- CAD librarians and mask-data preparation staff;
- MOSIS service operators;
- standards and PDK-maintenance work.

The manufacturing history is incomplete if it records only equipment inventors and ignores the people who kept the tools calibrated, loaded, repaired, qualified, and documented.
