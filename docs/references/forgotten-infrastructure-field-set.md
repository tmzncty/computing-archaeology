# Forgotten Infrastructure Field Set — Source Map

This source map supports the field set on punched-card sort/merge processing, RAMAC disk access, PDP-11 UNIBUS, Multics, MOS 6502 cost-driven design, and VT100 compatibility.

It is not a substitute for article-level footnotes.

The main purpose is to preserve **source type and caveat** so that later contributors do not flatten manuals, oral histories, corporate retrospectives, and preservation sites into one undifferentiated category.

## Cross-field methodological cautions

### Do not equate mechanism with intention

An experiment may show that ordered streams reduce comparisons or that smaller die can improve synthetic yield economics. It does **not** prove that every historical actor used the same model.

### Do not flatten “firsts”

RAMAC is safely described as the first **commercially shipped moving-head magnetic disk storage system / first computer system using such a random-access disk drive** when supported by CHM/IBM context. Avoid expanding this into broader claims about the first random-access storage of any kind.

### Participant testimony is indispensable and interested

Peddle, Mensch, RAMAC engineers, and Multics participants knew details unavailable elsewhere. They also remembered events from particular positions and sometimes disagreed over credit.

Use oral history as evidence, not omniscience.

### Preservation hosts deserve credit

Bitsavers, the Multics History Project, CHM, RAMAC restoration communities, and individual scanners are not the original authors of manufacturer documents, but without them the evidence would be much harder to audit.

Cite both layers appropriately.
