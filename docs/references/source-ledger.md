# Source Ledger

This file tracks high-value source collections that support current and future excavations. It is a research map, not a substitute for article-level citations.

The repository prefers primary engineering documents and well-provenanced archival material wherever possible. A link appearing here does **not** mean every statement on that page should be accepted uncritically.

## Field-set source maps

Some excavation rounds now have a dedicated source map because the number and kinds of sources exceed what is useful in one global index.

## Bitsavers and independent preservation

https://bitsavers.org/

Bitsavers is essential infrastructure for this repository. Cite it as the preservation host while retaining the original manufacturer/author, document title, form number, and date as the bibliographic source.

Independent specialist archives are also important when they preserve primary manuals not publicly hosted by the original manufacturer.

## Source-handling rule

For every source ask:

1. Who created it?
2. When?
3. For what purpose?
4. What did the creator know firsthand?
5. What incentives or institutional interests shaped it?
6. Is it a primary document, object record, institutional synthesis, oral history, retrospective, reconstruction, advertisement, or tertiary summary?
7. Does another independent source corroborate a strong claim?
8. If the source is a preservation host, who created the original document?
9. If the claim says “first,” what exact criterion is being used?
10. If a modern model is used, are its invented parameters clearly separated from historical measurements?

A source ledger is useful only if it makes future claims easier to audit.
