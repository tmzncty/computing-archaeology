# Build-up substrate stack

This synthetic model compares increasing package build-up layers with a simple routing-capacity proxy, cumulative layer-survival term, and via-count burden.

Run:

```bash
python experiments/build-up-stack/build_up_stack.py
```

All values are hypothetical. This is **not** an ABF, BT-resin, package-substrate, via-yield, or reliability model.

The narrow lesson is that more build-up layers can create routing opportunity while also multiplying lamination, alignment, via, and defect opportunities.
