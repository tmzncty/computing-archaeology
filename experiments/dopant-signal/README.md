# Dopant Signal Experiment

Question:

> When does intentional doping dominate uncontrolled background impurity?

This toy model compares an intended dopant concentration with a synthetic background-contamination level and reports the signal-to-background ratio.

It demonstrates why extreme purity is a prerequisite for predictable semiconductor engineering.

Run:

```bash
python experiments/dopant-signal/dopant_signal.py
```

The concentrations are synthetic teaching values, not measurements from Bell Labs, TI, Fairchild, or a modern wafer supplier.
