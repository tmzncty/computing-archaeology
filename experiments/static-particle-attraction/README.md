# Static particle attraction

Run:

```bash
python experiments/static-particle-attraction/static_particle_attraction.py
```

This synthetic model keeps two consequences of static charge separate:

- a direct ESD-like electrical-damage channel;
- a particle-attraction channel.

The point is that electrostatic control in semiconductor manufacturing is not only about preventing sparks.

## Historical status

All values are normalized and synthetic.

This is not an ESD qualification method, field solver, reticle model, or facility-control specification.

See [`../../docs/facilities/why-static-charge-became-a-yield-problem.md`](../../docs/facilities/why-static-charge-became-a-yield-problem.md).
