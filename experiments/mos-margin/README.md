# MOS Margin Experiment

Question:

> Why does process variation matter more as circuit margins tighten?

This synthetic model samples a threshold-like device parameter and counts devices that fall inside a chosen logic/process window.

Run:

```bash
python experiments/mos-margin/mos_margin.py
```

The distributions are invented. This is not a model of any Fairchild, Intel, or Bell Labs MOS process.
