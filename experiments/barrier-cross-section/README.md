# Barrier cross-section

A synthetic geometry model paired with `docs/materials/why-barrier-layers-became-hidden-metals.md`.

It keeps liner thickness fixed while shrinking a square interconnect cross-section, exposing the growing fraction of area consumed by the barrier/liner.

It is not a real diffusion-barrier thickness recommendation, resistance extractor, or process model.

```bash
python experiments/barrier-cross-section/barrier_cross_section.py
```
