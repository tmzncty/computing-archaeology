# Precursor Cycle Window

A synthetic ALD-like model for two competing requirements: enough precursor dose to approach surface saturation and enough purge to remove residual gas before the next half-cycle.

Run:

```bash
python experiments/precursor-cycle-window/precursor_cycle_window.py
```

This is not a reactor model or process recipe. It only demonstrates why “self-limiting chemistry” still needs a useful dose/purge operating window.
