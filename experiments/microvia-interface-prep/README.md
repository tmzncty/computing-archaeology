# Microvia interface prep

A synthetic model paired with `docs/pcb/why-laser-microvias-needed-desmear-and-seed.md`.

It gives cleaning a benefit (residue removal) and a cost (surface damage), then maps both into a seed-continuity and final-reliability proxy.

It is not a desmear recipe, laser setting guide, electroless-copper model, or PCB reliability predictor.

```bash
python experiments/microvia-interface-prep/microvia_interface_prep.py
```
