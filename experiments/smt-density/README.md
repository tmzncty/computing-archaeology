# Surface-Mount Density Experiment

Question:

> How does removing through-hole keepout from every component lead change board routing pressure?

This toy model compares synthetic area consumed by component body plus lead/hole keepout for through-hole and surface-mount assemblies.

Run:

```bash
python experiments/smt-density/smt_density.py
```

The dimensions are invented. It demonstrates geometric pressure, not a historical board-house process.
