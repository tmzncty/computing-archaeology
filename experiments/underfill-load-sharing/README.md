# Underfill load sharing

A synthetic model paired with `docs/packaging/why-underfill-became-a-mechanical-interface.md`.

It transfers an increasing fraction of thermal-mismatch strain away from solder bumps as underfill coupling rises, while also increasing a separate synthetic stress channel into the die/package stack.

It is not a finite-element model, material-selection guide, or lifetime predictor.

```bash
python experiments/underfill-load-sharing/underfill_load_sharing.py
```
