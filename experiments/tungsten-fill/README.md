# Tungsten fill

A deliberately synthetic recessed-contact geometry model paired with `docs/materials/why-wf6-made-tungsten-a-contact-metal.md`.

It compares line-of-sight deposition, conformal deposition, and a conceptual nucleation-plus-bulk-fill strategy as feature aspect ratio rises.

The numbers are not historical dimensions, CVD kinetics, deposition rates, or equipment data. The experiment only exposes why deep recessed contacts reward conformality and controlled nucleation.

Run:

```bash
python experiments/tungsten-fill/tungsten_fill.py
```
