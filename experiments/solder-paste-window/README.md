# Solder paste window

A synthetic model paired with `docs/pcb/why-solder-paste-became-a-printable-material.md`.

It couples aperture/particle geometry to a simple printing score and gives smaller particles a higher synthetic oxide-surface burden that must be handled by flux.

It is not a stencil-design rule, alloy model, flux recommendation, or reflow profile.

```bash
python experiments/solder-paste-window/solder_paste_window.py
```
