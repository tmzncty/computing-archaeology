# Design-Rule Interface

This toy model illustrates a social/manufacturing tradeoff:

> conservative design rules can sacrifice raw density in exchange for a more stable interface between designers and a fabrication process.

Run:

```bash
python experiments/design-rule-interface/design_rule_interface.py
```

The model is deliberately abstract. It does not represent lambda rules, a historical MOSIS process, a PDK, or any foundry's actual design margins.

See [`../../docs/manufacturing/why-design-rules-became-an-interface-to-the-fab.md`](../../docs/manufacturing/why-design-rules-became-an-interface-to-the-fab.md).
