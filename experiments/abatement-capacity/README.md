# Abatement capacity

Run:

```bash
python experiments/abatement-capacity/abatement_capacity.py
```

The model adds synthetic process-tool exhaust/abatement demand onto one shared facility capacity.

It illustrates why adding a healthy process tool can still require a building-level upgrade.

## Historical status

All capacity and demand values are synthetic normalized units.

This is not a ventilation, scrubber, fire-protection, chemical, or environmental design calculation.

See [`../../docs/facilities/why-exhaust-and-abatement-became-part-of-the-process.md`](../../docs/facilities/why-exhaust-and-abatement-became-part-of-the-process.md).
