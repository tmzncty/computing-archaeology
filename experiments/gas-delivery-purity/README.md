# Gas delivery purity

Run:

```bash
python experiments/gas-delivery-purity/gas_delivery_purity.py
```

The model begins with a synthetic high-purity source gas and adds a small contamination contribution at each downstream component.

Its only purpose is to illustrate why source-gas purity does not automatically guarantee point-of-use purity.

## Historical status

All ppb values are synthetic.

This is not a SEMI standard, process recipe, safety calculation, or gas-system design tool.

See [`../../docs/facilities/why-specialty-gases-became-a-fab-nervous-system.md`](../../docs/facilities/why-specialty-gases-became-a-fab-nervous-system.md).
