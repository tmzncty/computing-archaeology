# Tubing extractables / fluid-path accumulation

This synthetic experiment treats a high-purity chemical path as a sequence of wetted components, each contributing a small contamination increment.

Run:

```bash
python experiments/tubing-extractables/tubing_extractables.py
```

The numbers are hypothetical. This is **not** a PFA/PTFE/PVDF/stainless-steel comparison, a chemical-delivery qualification model, or a safety tool.

The lesson is simply that source purity is not point-of-use purity: small contributions from tanks, tubing, valves, housings, and fittings can accumulate across a delivery network.
