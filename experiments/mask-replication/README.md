# Mask Replication Experiment

Question:

> Why is a defect in a reusable production mask qualitatively different from a random defect on one die?

The model compares a systematic mask defect repeated across every exposure with independent random die failures.

Run:

```bash
python experiments/mask-replication/mask_replication.py
```

The probabilities are synthetic. The experiment demonstrates failure structure, not a historical lithography yield.
