# Foundry Boundary Experiment

Question:

> How can a large fixed fabrication investment change which product volumes can economically support owning a fab?

This synthetic model compares:

- an integrated-fab scenario with high fixed cost and lower variable manufacturing cost;
- a foundry-service scenario with near-zero modeled fab fixed cost and higher per-unit manufacturing price.

Run:

```bash
python experiments/foundry-boundary/foundry_boundary.py
```

All monetary values are invented. The model demonstrates cost structure, not historical TSMC, Intel, Fairchild, or any other company's actual economics.
